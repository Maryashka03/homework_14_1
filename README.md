Домашняя работа 14.1 — Введение в ООП

Описание проекта

Проект посвящён изучению объектно-ориентированного программирования (ООП) на Python.

В рамках домашнего задания реализованы два класса:

Product

Класс описывает товар и содержит следующие атрибуты:

- "name" — название товара;
- "description" — описание товара;
- "price" — цена товара;
- "quantity" — количество товара в наличии.

Category

Класс описывает категорию товаров и содержит:

- "name" — название категории;
- "description" — описание категории;
- "products" — список товаров категории.

Также реализованы атрибуты класса:

- "category_count" — общее количество категорий;
- "product_count" — общее количество товаров.

Счётчики автоматически обновляются при создании объектов.
