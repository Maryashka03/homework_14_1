# Домашние работы Skypro — Python

## Домашняя работа 14.1 — Введение в ООП

Проект посвящён изучению объектно-ориентированного программирования (ООП) на Python.

Реализованы классы `Product` и `Category`.

### Product

Класс описывает товар и содержит атрибуты:

- `name` — название товара;
- `description` — описание товара;
- `price` — цена товара;
- `quantity` — количество товара в наличии.

### Category

Класс описывает категорию товаров и содержит:

- `name` — название категории;
- `description` — описание категории;
- `products` — список товаров категории.

Реализованы счётчики:

- `category_count` — общее количество категорий;
- `product_count` — общее количество товаров.

## Домашняя работа 16.1 — Наследование

Добавлены классы-наследники класса `Product`:

- `Smartphone` — класс для описания смартфонов;
- `LawnGrass` — класс для описания газонной травы.

Для смартфонов добавлены атрибуты производительности, модели, памяти и цвета.

Для газонной травы добавлены атрибуты страны-производителя, срока прорастания и цвета.

Доработано сложение товаров: складывать можно только товары одного класса. При попытке сложить товары разных классов возникает `TypeError`.

Добавлена проверка типа товара при добавлении в категорию.

## Домашняя работа 16.2 — Множественное наследование

В проект добавлен абстрактный базовый класс `BaseProduct`, от которого наследуется класс `Product`.

Реализован абстрактный метод `__str__`.

Добавлен миксин `PrintMixin`, который:

- выводит информацию об объекте при его создании;
- использует метод `__repr__` для представления объекта;
- передаёт управление конструктору родительского класса через `super()`.

Класс `Product` наследуется от `PrintMixin` и `BaseProduct`.

Классы `Smartphone` и `LawnGrass` наследуются от `Product`.

Для новой функциональности добавлены тесты.
